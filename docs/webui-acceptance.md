# Web UI 验收清单

本清单区分**无 GPU 的自动化/模拟验收**与**必须由真实 NVIDIA 环境执行的验收**。模拟引擎输出合成测试音，不代表真实音质、速度、显存占用或 CUDA 正确性。

## 模拟与自动化验收范围

- API：默认值与参数透传、结构化错误、语言、上传限额、媒体 Range/HEAD 与路径白名单、音色/TXT/描述兼容、输出参数历史。
- 并发：推理、ABX、训练、导出共同互斥；同时提交只接受一个，停止/失败后释放；CPU ASR 不误占 GPU 锁。
- 项目：创建/克隆/删除确认、输出保留、数据与验证清单分离、过期检测、评估参考持久化、种子真实传给训练器。
- 校对：会话与角色安全、草稿保存/放弃/取消、冲突保留、单条识别不自动保存、批量识别停止后继续、快捷键与不自动播放。
- ABX：相同配对种子、盲测映射不在揭晓前的试次响应中泄漏、评分立即持久化、揭晓锁定、未完成片段可补齐。
- 导出：参数与 CPU 子进程、取消、失败恢复、下载令牌、验证证据严格为真才发布，不把缺失/字符串/数字当作通过。
- 前端：真实组件配合模拟 HTTP，含语音、对话、库、系统、项目、训练、ABX、导出与活动；类型、ESLint、翻译完整性、可复现生产构建。
- 更新：旧 1.1.0 清单解析器接受新包；必需启动文件/资源齐全；受保护环境文件没有改动；ZIP 更新相关回归通过。

测试命令和开发服务器用法见[开发与维护](development.md)。具体自动化结果与截图须以该次提交的验收记录为准，不应只凭本清单视作通过。
