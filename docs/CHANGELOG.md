# 更新日志

本项目的所有版本变更都记录在这里。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)：

- **修订号**（1.0.**1**）：只有修复，用法不变；
- **次版本号**（1.**1**.0）：新增功能，原有用法和数据仍然可用；
- **主版本号**（**2**.0.0）：不兼容的改动，例如训练项目或数据目录的格式变化，需要手动处理。

标有 **⚠️ 需要重新安装** 的版本改动了运行环境，`3- update.bat` 会拒绝更新，需要重新下载并运行 `1- install.bat`。没有这个标记的版本都可以直接一键更新。

当前版本显示在界面标题旁，启动时控制台也会打印一行 `[startup] IndexTTS 2.5 Easy GUI v…`。

## [1.1.0] - 2026-11-10

### 新增

- LoRA 项目可以关联独立的验证语料目录，复用语音识别和听音校对，并生成单独的验证清单。开启验证时，训练前会检查清单状态和重复音频。
- 训练时可以随检查点或按自定义步数间隔计算验证损失，并在 TensorBoard 同图对照训练和验证曲线。正常结束时会验证最终权重。

### 修复

- LoRA 验证间隔填 `0` 或留空都可以保存，训练时随检查点验证。

## [1.0.0] - 2026-11-07

第一个带版本号的版本。此前已经有过多次实用的迭代，记录在下方的 [1.0.0 之前](#100-之前)；1.0.0 表示这些功能作为一个整体已经可以日常使用：

- 声音库，单条合成和多角色对话合成，长文本自动分段，多种情绪控制方式；
- 数据准备：SenseVoice 本地识别补全文本，内嵌的听音校对工作台；
- LoRA 训练（实验性）与盲测对比；
- 导出 GPT 检查点，供 ComfyUI 的 IndexTTS-2.5 节点加载；
- 简体中文界面（可切换英文），不需要 Git 的一键更新与回滚。

从带一键更新的版本（2026-11-06 之后的安装）升级时，不需要重新安装。

### 新增

- 版本号：界面标题旁和浏览器标签页标题显示当前版本，启动时控制台打印版本。
- 本更新日志（`docs/CHANGELOG.md`）。

### 修复

- README 顶部引用的界面截图 `assets/screenshot.png` 缺失。

## 1.0.0 之前

以下改动发生在引入版本号之前，按日期倒序列出，括号中是对应的提交。

### 2026-11-07

- 新增“🎧 盲测对比”页：先为两个适配器（或原始模型）生成配对音频，再以随机且平衡的顺序盲听评分，揭晓后给出胜出次数、平均偏好和符号检验结果；测试保存在 `outputs/abx/`，可中途停止后继续（`45ab323`）。
- 文档拆分为安装与配置、使用指南、更新与常见问题、开发与维护四份，并补充英文概览；移除上游 IndexTTS 的模型说明和只被它们引用的资源（`d9ece31`）。
- 修复：报错和加速组件说明中提到了不存在的 `install_accelerators.bat` 和未编号的旧脚本名，现在统一指向 `1- install.bat`、`2- run.bat`（`bca56d7`）。

### 2026-11-06

- 新增不需要 Git 的一键更新 `3- update.bat`：从 GitHub 下载 ZIP，只替换程序文件，保留个人数据，失败时自动还原，并支持回滚；运行环境的安装逻辑移到 `tools/install_runtime.bat`（`6fc81f7`）。
  **⚠️ 需要重新安装**：在此之前安装的副本还没有更新器，需要重新下载一次。

### 2026-11-05

- 新增“📦 导出 GPT 检查点”页：在 CPU 上把 LoRA 合并为完整的 FP32 检查点，可在浏览器下载或保存到服务器路径，导出任务可以取消（`3a5bb49`、`6490853`）。
- 数据准备整合听音校对工作台；校对后的文本有改动时，训练前会提示训练清单需要更新（`cfb1ba1`）。
- 新增本地 SenseVoice 语音识别，在 CPU 上为语料补全文本（`cf43f06`）。
- README 按集成后的识别和训练流程重写（`e2b24fd`）。

### 2026-10-31

- 新增命令行工具 `tools/merge_lora_to_pth.py`：把 GPT 的 LoRA 合并为完整检查点并校验（`26e6081`）。
- 新增简体中文界面，可切换回英文（`6ccdb41`）。
- 运行环境安装改为可复现，新增 `local-settings.bat` 保存本机的监听地址和代理设置，启动时自动准备 FFmpeg（`333911f`）。
  **⚠️ 需要重新安装**。

### 2026-08-22

- 新增实验性的数据准备和 LoRA 训练（`7cd880c`，原项目作者 Blakus）。
  **⚠️ 需要重新安装**。

### 2026-08-12

- 初版：IndexTTS 2.5 的 Windows 图形界面，包括声音库、单条合成和多角色对话合成（`871760b`，原项目 [Mixomo/IndexTTS-2.5-Easy-GUI](https://github.com/Mixomo/IndexTTS-2.5-Easy-GUI)，作者 Blakus）。
