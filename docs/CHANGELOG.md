# 更新日志

本项目的所有版本变更都记录在这里。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)：

- **修订号**（1.0.**1**）：只有修复，用法不变；
- **次版本号**（1.**1**.0）：新增功能，原有用法和数据仍然可用；
- **主版本号**（**2**.0.0）：重大界面/交互替换，或不兼容的数据/API 改动；是否需要迁移与重装由各版本单独说明。

标有 **⚠️ 需要重新安装** 的版本改动了运行环境，`3- update.bat` 会拒绝更新，需要重新下载并运行 `1- install.bat`。没有这个标记的版本都可以直接一键更新。

当前版本显示在界面标题旁，启动时控制台也会打印一行 `[startup] IndexTTS 2.5 Easy GUI v…`。

## [未发布]

**无需重新安装，可直接一键更新。** 已有项目、检查点和适配器继续使用。

### 新增

- 自动终止：根据验证损失判断过拟合或平台期。没有显著改善时进入观察期并加密验证；观察期内比谷底改善至少“最小改善幅度”就恢复正常，否则在耐心步数用完时自动结束训练，节省 GPU 时间。状态随检查点保存，续训时恢复。
- 最优适配器：开启自动终止后，验证损失每次刷新最低值都会把权重另存为 `best_adapter/`，可用于合成、盲测、导出、事后验证和续训。

### 改进

- 训练中同一步需要验证和保存检查点时，先验证再保存，使检查点记录的状态包含该步的验证结果。

## [2.2.0] - 2026-11-12

**无需重新安装，可直接一键更新。** 已有项目、清单、适配器和 TensorBoard 日志继续使用。

### 新增

- 事后计算验证损失：“输出文件”页自动列出适配器目录中的检查点和最终适配器，可勾选后用当前项目的验证集计算验证损失，可选原始模型基线。结果保存在适配器目录的 `validation_posthoc.json`，显示在表格、项目曲线和 TensorBoard 的 `posthoc` 运行中；验证集或权重变化后标为已过期。
- 提前结束：训练可在指定步数结束，学习率调度仍按计划总步数计算；之后从该步检查点续训，即可沿原计划继续。
- 区间密集验证：除全局验证间隔外，可为一个步数区间设置更小的验证间隔。
- 检查点和最终适配器额外保存 `adapter_state.json`，记录步数和是否提前结束，界面因此能显示最终适配器的步数。

## [2.1.0] - 2026-11-10

**无需重新安装，可直接一键更新。** 只修改前端界面，数据格式、API 和训练/推理行为不变。

### 改进

- 切换页面、打开项目、切换项目标签页和音色库条目时，新内容以约 0.4 秒淡入并轻微上移；不会重建页面，未保存的表单与校对草稿保持不变。系统开启“减少动态效果”时不播放动画。
- 引入 12 栏文字网格与更明确的字号层级：页面标题前显示所属分组，标题和导语放大，操作按钮与标题对齐。
- 系统、语料、验证集和盲测设置/结果改为“左侧标题列 + 右侧内容”的分区，用细线分隔；合成、校对、训练等工作区保留浅灰圆角块。
- 侧栏改为白底/黑底，当前页用字重和强调色短竖条标出；顶栏更薄；对话框、标签页和折叠面板增加轻量淡入。

## [2.0.0] - 2026-11-10

**无需重新安装；已有数据格式和启动/更新入口保持兼容。** 主版本变化对应界面技术栈与交互方式的全面替换，不要求迁移用户数据。

### 改进

- 用 React + TypeScript + Vite SPA 和 FastAPI 替换 Gradio 页面；用户直接运行已构建前端，不需要 Node.js。
- 统一左侧导航、分层参数面板、明暗主题、中英文与键盘可访问性；高级设置按需展开，修改项标记并可恢复默认。
- 所有长任务提供进度、阶段、耗时、停止和明确终态；新增活动面板、断线重连、浏览器端提示音/授权通知与可展开控制台。
- 合成支持完整情感与解码设置、最多 12 轮对话、长文本分块，以及带参数的最近结果、复用与下载。
- 训练工作台将项目、语料/验证校对、训练监控、曲线与检查点产物串联；原校对的草稿保护、冲突检测、ASR 和清单语义保留。
- 盲测支持成对种子、停止后补齐、评分与确认揭晓；导出增加结构化验证证据展示，保留带令牌的模型/报告下载。
- 推理、训练、ABX 和导出共用原子活动锁；多应用测试上下文隔离、上传限额、媒体白名单和统一 API 错误覆盖回归测试。
- 提供隔离数据根的模拟引擎和演示初始化工具，允许无 GPU 联调；真实 GPU/模型验收另见清单，模拟测试不代表真实音质或性能已通过。

### 兼容性

- `easy_gui.py` 成为保留互斥锁与更新恢复检查的薄启动器；`2- run.bat` 和 ZIP 更新器入口不变。
- 前端源码位于开发专用 `frontend/`，运行产物放在旧更新器允许的 `tools/gui_web/`；不扩展旧清单允许的根路径。
- 不改动 Python/依赖锁定、安装和验证脚本等环境输入。已有音色/TXT、情感描述、项目/清单、训练结果、适配器与 ABX 会话继续使用。
- 页面不再使用 Gradio；既有环境中的依赖可以保留，无需卸载或重装。

## [1.1.0] - 2026-11-10

### 新增

- LoRA 项目可以关联独立的验证语料目录，复用语音识别和听音校对，并生成单独的验证清单。开启验证时，训练前会检查清单状态和重复音频。
- 训练时可以随检查点或按自定义步数间隔计算验证损失，并在 TensorBoard 同图对照训练和验证曲线。正常结束时会验证最终权重。

### 修复

- LoRA 验证间隔填 `0` 或留空都可以保存，训练时随检查点验证。

## [1.0.0] - 2026-11-07

第一个带版本号的版本。此前已经有过多次实用的迭代，记录在下方的 [1.0.0 之前](#100-之前)；1.0.0 表示这些功能作为一个整体已经可以日常使用：

- 声音库，单条合成和多角色对话合成，长文本自动分段，多种情绪控制方式；
- 数据准备：SenseVoice 本地识别补全文本，内嵌的听音校对工作台；
- LoRA 训练（实验性）与盲测对比；
- 导出 GPT 检查点，供 ComfyUI 的 IndexTTS-2.5 节点加载；
- 简体中文界面（可切换英文），不需要 Git 的一键更新与回滚。

从带一键更新的版本（2026-11-06 之后的安装）升级时，不需要重新安装。

### 新增

- 本更新日志（`docs/CHANGELOG.md`）。
