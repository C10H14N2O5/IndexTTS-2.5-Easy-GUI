# 使用指南

2.0 的左侧导航为 **语音合成、音色库、训练项目、盲测对比、导出、系统**。安装与启动入口不变，见[安装与配置](installation.md)。已有音色、项目、语料、适配器和 ABX 会话无需迁移。

## 界面与反馈

- 先填写主要内容；情感、节奏、解码和训练高级参数按需展开。修改过的参数有标记，可单项恢复默认。
- 操作按钮显示处理中状态；长任务提供阶段、进度、耗时与停止操作。任务成功、失败、停止是不同结果，不必靠观察控制台判断是否响应。
- 顶栏“活动”可查看近期任务与消息；控制台抽屉用于排查细节。切换页面不会停止后台任务，刷新页面后会重新同步当前状态。
- 顶栏可切换中文/英文和浅色/深色/跟随系统。界面宽度至少 1024px，较窄窗口会把侧栏折叠为图标。
- 切换页面和项目标签页时内容会短暂淡入，不会清空正在编辑的内容。如果操作系统开启了“减少动态效果”（Windows：设置 → 辅助功能 → 视觉效果 → 动画效果），界面不播放这些动画。
- 断线时会提示自动重连；恢复后重新同步快照。如果服务器已经退出，请先重新启动服务。
- **演示模式横幅表示音频和训练结果是模拟数据**，不能用于判断声音质量。

## 音色库

在“音色库”保存常用的参考音频，之后在合成页直接选用。

1. 上传或录制简短、清晰、只有一位说话者的音频；可用“裁剪”保留选中片段，原文件不变。
2. “参考音频文本”可选，填写音频里实际说的话，而不是要合成的内容；也可以先识别再人工检查。
3. 保存后文件及同名 TXT 存入 `voices/`，重启后仍可使用。音色可以改名、编辑转写或删除；重名覆盖需要确认。
4. 同页的“情感描述”保存常用情绪文字，供合成/对话调用，保存在 `emotion_descriptions/`。

上传上限为 200 MiB。麦克风通常只在 localhost 或 HTTPS 上可用：通过局域网 IP 的 HTTP 访问时，界面会说明录音不可用，仍可上传文件。浏览器首次录音需要麦克风权限。

## 语音合成

在“单人语音”与“多角色对话”之间切换。草稿保存在当前浏览器，不同电脑/浏览器之间不会自动共享。

### 单人语音

1. 在右侧“选择音色”中选择库中音色，或上传/录制一段参考音频。
2. 输入目标文本，按需选择语言：中文、英文、日文、西班牙文或阿拉伯文。
3. 可选：展开“生成设置”，选择训练好的 LoRA 适配器；不选时使用原始模型。
4. 点击“生成语音”。任务卡显示阶段与进度，完成后可试听和下载。

“保存输出”开启时，WAV 和生成参数保存到 `outputs/`；关闭时只保留临时预览。下方“最近结果”可试听、下载、复用参数或删除；旧版本的 WAV 没有参数记录时仍可播放，但不能恢复未知参数。

**长文本**：在“文本分块”中选择自动段落/句子、句号、段落、行或说话轮次等方式。各块分别合成，再按块间静音拼接。停止在当前块完成后生效，不强行中断 CUDA 内核；已成功完成的整体结果不会被误标为取消。

### 情感与表达

| 模式 | 说明 |
| --- | --- |
| 与音色参考一致 | 情感和语调跟随参考音频 |
| 情感参考音频 | 音色来自参考音频，情感来自另一段音频 |
| 情感向量 | 调整高兴、愤怒、悲伤、害怕、厌恶、低落、惊讶、平静 8 维；37 个预设可一键填入并继续微调 |
| 情感描述 | 用文字描述情绪和语调，可从描述库选用，由 QwenEmotion 理解 |

“情感强度”控制影响强弱，越高不一定越自然。“随机情感采样”增加变化，也会降低可复现性。

### 多角色对话

每轮分别选择**已保存的音色**、填写文本，并选择情感向量预设或已保存的情感描述。可插入、复制、上移、下移、清空或删除，最多 12 轮。点击“生成对话”后，各轮按设置的轮次间隔拼成一个 WAV；停止在当前轮次结束后生效。

### 常用参数

| 参数 | 作用 |
| --- | --- |
| 时长系数 | 1 为正常；小于 1 更快，大于 1 更慢 |
| 文本规范化 | 将数字、日期和单位转换为读法 |
| 段间静音 | 模型自动拆分片段之间的停顿；与显式文本分块的块间静音分开设置 |
| 每段最大文本 Token 数 | 模型内部单段文本长度限制 |
| 启用采样 | 关闭后通常更稳定，但不保证跨硬件完全一致 |
| 温度、Top P、Top K | 控制采样候选范围和随机程度 |
| 束搜索宽度 | Beam search 候选数量 |
| 重复惩罚、长度惩罚 | 调整重复抑制与序列长度偏好 |
| 最大声学 Token 数 | 限制单段生成长度 |

BF16、GPT 潜变量路径、torch.compile 与 FlashAttention 移到“系统 → 运行时设置”，作用于所有后续合成任务。首次编译可能较慢；不可用选项会说明原因。FlashAttention 需要 BF16 和 Triton。详见[可选加速组件](installation.md#可选加速组件)。

## 训练项目

“训练项目”将原来的数据准备与 LoRA 训练整合在同一个项目中：**语料、训练、产物**。项目列表支持新建、克隆和输入名称确认删除。删除项目保留已有训练输出；清理输出需另行明确操作。

## 数据准备

在项目的“语料”页管理训练集与验证集；校对器是同一页面中的 React 工作台，不再嵌入旧页面。

### 准备语料

音频需要**事先切好片**，每段配一个同名 TXT：

```text
my_voice/
├─ 001.wav
├─ 001.txt
├─ 002.wav          # 缺失/空 TXT 可以识别补齐
└─ session_02/
   ├─ 001.wav
   └─ 001.txt
```

递归扫描支持 WAV、FLAC、MP3、M4A、OGG、AAC；不同子目录的同名文件按相对路径区分。TXT 必须是音频里实际说出的原文，不是翻译。原音频不会被修改。

### 操作流程

1. 新建/打开项目，选择**服务器上的语料目录**、训练语言并保存。浏览按钮浏览的是运行服务的电脑，不是远程浏览器的电脑。
2. 点击“识别缺失文本”，为缺失或空 TXT 生成文本，已有非空文本跳过。可中途停止，完成的内容保留，下次只处理缺失项。
3. 使用搜索、缺失文本/已校对筛选逐条试听、编辑。可调播放速度；切换条目不会自动播放。
4. “保存”只保存文本；“保存并下一条”还会标为已校对并前进；单条重新识别只填入草稿，**不会自动保存**。
5. 完成后“更新训练清单”，再前往项目“训练”页。

快捷键：`Ctrl+S` 保存，`Ctrl+Enter` 保存并下一条，`Alt+Space` 播放/暂停；浏览器占用快捷键时使用按钮。未保存时切换条目、目录、项目或页面，会询问保存、放弃或取消；取消后保留草稿和原来的上下文。

### 为什么保存后还要更新清单？

训练读取 `training/datasets/<项目>/manifest.jsonl`，其中的文本是生成清单时的快照。保存 TXT 不会自动更新它。

- 更新清单读取当前保存的 TXT，不重新识别；不符合时长限制的音频会被过滤。扫描总数不等于有效训练样本数，以清单统计为准。
- 语料变化后显示“待更新”；过期清单不能启动训练。
- 训练中仍可校对，但需训练结束后更新清单。
- TXT 以 UTF-8 保存；第一次修改已有 TXT 时备份到语料目录的 `.proofread/backups/`。
- `.proofread/state.json` 只存校对进度，不决定样本是否参与训练；文本变化后旧校对标记失效。
- 检测到外部修改时提示冲突，不静默覆盖；先复制保留草稿，再加载磁盘文本。

### 语音识别

SenseVoiceSmall Q8 在 CPU 上自动判断语言，用于语料、音色库、合成参考和训练评估参考。请求串行处理，单条超时 180 秒；先转换临时副本以兼容中文路径。失败不静默切换其他模型，日志位于 `.runtime/asr/logs/`。运行时需先[导入 ASR 程序和模型](installation.md#导入-asr-程序和模型)。

### 验证集

1. 保存训练语料与语言后，切换“验证集”。可显式保存建议目录 `validation/<项目>/`（保存时创建），或选择已有服务器目录。
2. 使用相同的识别、试听和校对流程，更新独立的 `training/datasets/<项目>/validation.jsonl`。不会覆盖训练清单。
3. 选择未参与训练的录音。开启验证后会检查清单有效性、相同路径和字节完全相同的重复音频；剪切或重编码的重复片段仍需自行排除。

## LoRA 训练

这是**实验性 GPT LoRA**：只训练 GPT 模块的 LoRA 参数，其他模块保持不变；训练目标是还原声学 token。适配器使用时仍需原始 IndexTTS 模型与参考音频。

### 开始训练

1. 打开已有有效清单的项目“训练”页，填写适配器名称。
2. 选择显存预设并点击“推荐设置”。它依据语料统计建议参数，**不实际测量显存**；之后可以调整。
3. 按需要展开训练长度、LoRA、优化器与评估设置，并保存。新项目默认：学习率 `4e-5`、1000 步、每 100 步保存、梯度裁剪 `0.5`、随机种子 `1234`、启用评估试听。旧项目读取其已保存值。
4. 评估试听需要评估文本和参考音频；每次保存检查点时生成试听音频。参考可上传、裁剪、转写，并持久化到项目中。
5. 点击“保存并开始训练”时会先校验清单、参数和共享资源；开始后显示步数、loss、进度与曲线。停止是协作式请求，当前步骤完成后结束。

推理、训练、ABX 生成与导出共享活动锁，冲突时按钮说明原因或返回明确繁忙错误，不并行抢占资源。

### 验证损失

首次绑定验证目录会启用验证。关闭时无需验证集也可训练；目录、清单和间隔设置保留。间隔为 `0`/留空时随检查点验证，正整数表示优化器步间隔；正常训练结束会验证最终权重。

项目内曲线可对照训练与验证损失，也可打开 TensorBoard 的 **Custom Scalars → Loss → Training and validation**。同一验证集上，训练损失持续下降而验证损失上升可能表示过拟合；切换验证集时可查看 **Text → validation/dataset** 的指纹与样本数。验证失败会保留当前步检查点后停止，修正后可续训。

**TensorBoard 默认仅监听服务器的 127.0.0.1**。远程浏览器上的同名 localhost 指向客户端电脑；需要在服务器本机打开，或自行配置安全隧道。界面不会替服务器自动弹浏览器。

### 产物与续训

```text
training/outputs/<适配器名称>/
├─ checkpoint-step-000100/
├─ ...
└─ final_adapter/
```

“输出文件”页查看检查点、评估音频与曲线，并可转到合成、盲测或导出。在训练设置中选择“恢复训练检查点”可续训。比较配置时使用不同适配器名称，保持同一参考音频与同一段训练外文本；先跑短训练并试听，不只看 loss 选权重。

**不同实验请使用不同适配器名称。** 训练沿用旧版的输出目录复用行为：同名目录中的同名模型文件可能被后续训练更新。需要保留的结果先备份，不要把“从头开始”理解为自动创建一个全新目录；导出的目标文件则始终禁止覆盖。

## 盲测对比

比较两个不同适配器 A/B，任一边可为原始模型。选择保存的参考音色、语言、每行一句测试文本、每句 1–5 次生成（默认 2），页面预先显示总组数与音频数。

“创建并生成”将当前合成解码参数与系统运行时选项复制到会话；后续修改不会改变已保存会话。情感跟随参考音频。程序先生成 A 再生成 B，同一句同一次使用相同随机种子，以减少随机差异，但不保证完全消除。

生成可停止；已完成片段保留，重启后也可以“继续生成”，只补缺失片段。生成期间其他 GPU 活动被互斥保护。

### 评分与揭晓

每组展示目标文本、参考音频、随机且平衡排列的“样本 1/2”。五档评分从样本 1 明显更好到样本 2 明显更好；即时保存，揭晓前可修改/清空，并可跳到下一个未评组。

“揭晓结果”需要确认，之后评分锁定，未评分组不计入。报告包含 A/B 胜出数、平局、平均偏好与标准误、双侧精确符号检验 p 值，以及每组身份明细。`p < 0.05` 表示本次样本的统计证据；“未发现显著差异”不等于两者完全一样。

建议每句约 5–15 秒、至少 10–20 组；排除平局后少于 6 组不可能达到显著（6:0 时 p≈0.031，5:0 时 p≈0.063）。这不是严格防作弊系统：音频文件名随机、页面隐藏映射，但本机文件与原始日志不构成安全隔离。

会话保存于 `outputs/abx/<会话>/`，包括 JSON、参考副本与随机名音频。系统清理顶层输出不会删除 ABX 子目录。

## 导出 GPT 检查点

“导出”将 LoRA 与原始 GPT 权重合成完整 FP32 `.pth`。后台使用 CPU，不支持“跳过 CPU 验证”；与训练/推理共享锁，以避免资源及模型状态冲突。

1. 选择 `final_adapter`、检查点，或浏览自定义适配器目录。
2. 选择“浏览器下载”并填写文件名，或“服务器路径”并填写/浏览目标 `.pth` 路径。服务器路径不是客户端保存位置。
3. 展开底模与验证设置，确认训练时的原始 FP32 `gpt.pth` 和 `config.yaml`。适配器里记录的历史模型目录只是元数据，不证明当前底模身份。可填写预期部署底模，先比较 SHA-256。
4. 导出后查看阶段、进度、日志与结构化验证报告。可请求取消，已有目标不覆盖。
5. 仅成功且验证证据通过时提供模型与 `.merge.json` 下载。报告缺失的项目显示“未验证”，不假装通过。

检查包括结构、数值、合并前后输出误差、源文件未改变及保存/重载张量一致。下载链接含临时令牌，请勿公开分享。日志位于 `.runtime/export/logs/`。

### 命令行导出

```powershell
.\.venv\Scripts\python.exe -B tools\merge_lora_to_pth.py `
  --base models/IndexTTS-2.5/gpt.pth `
  --config models/IndexTTS-2.5/config.yaml `
  --adapter training/outputs/my_voice/final_adapter `
  --output outputs/merged/my_voice.pth
```

可加 `--expected-base <部署用的 gpt.pth>` 比较底模哈希。ComfyUI 中导出文件只替代 GPT，其余模型与参考音频仍需保留。若插件提供 `GPT Checkpoint Selector`，把 `.pth` 放入 `models/IndexTTS-2.5/gpt_checkpoints/`，刷新后选择并连接到合成节点的 `gpt_checkpoint`。合并与实时 LoRA 效果可能略有差异，仍需试听。

## 系统与安全

“系统”查看 CUDA/显存、加速能力、ASR、模型状态；可卸载模型释放显存，管理外观、完成提示音与通知。声音由**浏览器**播放，通常需先与页面交互；通知必须主动授权，局域网 HTTP 通常无法使用，不会反复弹权限框。

删除全部音色或顶层输出需要输入确认文字；不会顺带清理训练产物和 ABX 会话。此工具没有账户鉴权，只适合可信本机/局域网，**不要直接开放到公网**。
