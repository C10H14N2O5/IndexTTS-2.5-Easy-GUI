# 更新与常见问题

## 更新

适用于下载 ZIP 安装、并且已经运行过 `1- install.bat` 的部署，不需要 Git。

```powershell
& '.\3- update.bat'             # 更新到最新版本
& '.\3- update.bat' --check     # 只检查有没有新版本、能否直接更新
& '.\3- update.bat' --rollback  # 回到上一次更新之前的版本
```

也可以直接双击 `3- update.bat`。更新完成后重新启动 GUI。

### 更新前

关闭 GUI、训练、导出和安装窗口。更新程序不会强制结束它们，检测到它们在运行时会停止更新。

### 会更新什么、保留什么

- **更新**：程序文件（代码、脚本、文档）。新版本从 GitHub 上本项目的 `main` 分支下载。
- **保留**：模型、语料、训练项目和输出、声音库、`.venv/`、`.runtime/` 中的其他数据、`local-settings.bat`。
- **不会**自动升级依赖、运行安装程序，也不会改动 CUDA、ASR 程序或模型。

### 更新被拦住的几种情况

| 提示 | 原因与处理 |
| --- | --- |
| 依赖或环境定义发生变化 | 新版本改了依赖、Python 版本或安装脚本。此时还没有替换任何文件。请到 GitHub 下载新版本后重新运行 `1- install.bat`，或者暂时不更新 |
| 与本地文件冲突 | 你修改过某些程序文件，或者新版本要放的文件和你自己的文件同名。按提示处理列出的文件后再更新 |
| 目录中存在 `.git` | 这是 Git 开发目录，请用 `git pull` 更新 |

### 失败、中断与回滚

- 替换文件或更新后的自检失败时，会自动恢复到更新前的状态。
- 如果更新被断电或强制关闭打断，再运行一次 `3- update.bat`，它会先完成恢复。在恢复完成之前，GUI 和安装程序都会拒绝启动。`--check` 不会执行恢复。
- `--rollback` 可以回到上一次成功更新之前的版本，只能回退一次。如果更新之后你又修改过程序文件，回滚同样会提示冲突。
- 更新记录、日志和备份保存在 `.runtime/update/`。更新没完成时，请不要删除这个目录。

## 常见问题

**启动时提示有中断的更新需要恢复**
运行 `3- update.bat`（不带参数），等它完成恢复后再启动。

**提示项目环境未安装，或 CUDA / NumPy 验证失败**
确认 NVIDIA 驱动正常（命令行运行 `nvidia-smi`），然后重新运行 `1- install.bat`。启动窗口会显示具体是哪个版本或哪项导入出错。

**界面提示 Triton 或 FlashAttention 不可用**
先在“系统 → 运行时加速”中关闭对应选项，确认基础合成正常；再重新运行 `1- install.bat` 修复。详见 [可选加速组件](installation.md#可选加速组件)。

**模型缺失或下载失败**
重新运行 `2- run.bat`，它会继续下载缺失的文件。网络受限时，在 `local-settings.bat` 中配置代理，见 [本地设置](installation.md#本地设置)。

**端口被占用，或局域网内其他设备打不开**
在 `local-settings.bat` 中修改 `INDEXTTS_PORT`，或把 `INDEXTTS_HOST` 改成本机的局域网 IP。同时检查 Windows 防火墙是否放行这个端口。

**提示缺少 ASR 程序或模型**
按 [导入 ASR 程序和模型](installation.md#导入-asr-程序和模型) 导入，然后检查 `.runtime/funasr/import.json` 和 `models/asr/` 是否存在。

**识别失败、结果为空或超时**
查看错误信息中给出的 `.runtime/asr/logs/` 目录。单条识别的超时时间是 180 秒。处理好之后再点“识别缺失文本”，已有文本会自动跳过。

**训练清单显示“待更新”，或无法更新**
先保存项目（语料目录和训练语言）以及编辑框中的文本，等训练和批量识别都结束后，再点“更新训练清单”。

**安装后环境里还有 Whisper 相关的包**
这是正常的。界面中的识别功能已经全部改用 SenseVoice，但底层的一些代码仍然依赖这些包，所以保留了它们。
